# CAD status and next steps

The repository does not currently contain a verified full-assembly STEP export or editable source CAD model.

A full assembly model cannot be accurately generated from the firmware assumptions alone. Before creating it, measure or identify the actual board, sensor modules, connectors, mounting holes, and intended enclosure. The finished assembly should include the electronics and show how the parts are mounted.

When the real design is modeled, add:
- The full assembly STEP export.
- The editable native CAD source (for example, Fusion 360, FreeCAD, or Onshape).
- A screenshot of the complete assembly.
- Any enclosure or mounting-part print files.

Do not treat this status note as a substitute for the required CAD deliverables.
