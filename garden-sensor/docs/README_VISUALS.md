## Important distinction

The CAD illustration is a reference design based on assumed component dimensions. It is not a photograph, a measured fit-check, or proof that the hardware has been assembled. Add genuine photos of the actual project separately.

There is no custom PCB in this design, so do not add a fabricated PCB screenshot. The standard Pico development board is a commercially manufactured module, not a PCB designed or routed by this project.
