# Build journal

This file is intentionally an empty journal scaffold. Add your own dated entries as you work on the physical project. Do not submit it as a completed journal until it contains your real build notes and photographs.

## Entry format

For each actual work session, add a new section with:

- **Date and time spent:** Record the actual date and time you worked.
- **What I did:** Describe the work you personally completed.
- **What worked:** Record observations from the real build.
- **What did not work:** Record problems and how you responded.
- **Next step:** Record what you plan to try next.
- **Photo:** Embed at least one genuine photo from that work session, for example: `![Photo of the build](docs/images/your-photo.jpg)`.
